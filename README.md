## Installing

- **Windows:** if SmartScreen says "Windows protected your PC", click *More info → Run anyway*.
- **macOS:** open the .dmg, drag DraftCAD to Applications, then right-click → *Open* the first time. If it says the app "is damaged": `xattr -cr /Applications/DraftCAD.app`
- **Ubuntu/Debian:** `sudo apt install ./DraftCAD-Linux-amd64.deb`
- **Fedora/RHEL:** `sudo dnf install ./DraftCAD-Linux-x86_64.rpm`
- **AppImage:** `chmod +x DraftCAD-*.AppImage` and run it.
