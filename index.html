Installing

  • Windows: if SmartScreen says “Windows protected your PC”, click More info → Run anyway.
  • macOS: open the .dmg and drag DraftCAD to Applications. The first time, right-click the app → Open. If macOS says it “is damaged”, run xattr -cr /Applications/DraftCAD.app in Terminal.
  • Ubuntu / Debian: sudo apt install ./DraftCAD-Linux-amd64.deb
  • Fedora / RHEL: sudo dnf install ./DraftCAD-Linux-x86_64.rpm
  • AppImage: chmod +x DraftCAD-*.AppImage, then double-click it.
